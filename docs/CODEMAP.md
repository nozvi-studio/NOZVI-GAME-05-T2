Interaction (Phase 2, server-owned seats since T-1039): `apps/web/src/game/interaction/InteractionController.ts` owns targeting and prompts and sends `intent` messages (sit, toggleWork, wave); desk occupancy comes from room state via `apps/web/src/net/occupancy.ts` (`roomOccupancy`); seat sockets in `interaction/seats.ts`; `Player.applyServer` (`apps/web/src/game/player.ts`) seats / stands the local player only when the server reports it (predictor paused while seated, `Predictor.seat` / `unseat`); WASD while seated is just movement input, which the server turns into a stand; `Game.ts` wires E/G and prompt callbacks; `apps/web/src/ui/Prompt.tsx` renders the prompt through `App.tsx`. Tests: `apps/web/test/interactionController.test.ts`, `prediction.test.ts` (seat/unseat replay), `avatarClips.test.ts`, e2e `sit.spec.ts` and two-page `seats.spec.ts` (walks with keys via the DEV `setCameraYaw` hook) (REQ-INT-001/002/005, REQ-NET-002).

Phase 3 presence (REQ-UI-003): `apps/web/src/ui/employeeRoster.ts` (plain TS store over `employeeSource`, stable snapshot until join, leave, name, label or connection changes; "Reconnecting…" label while `connected = false`; `rebind` after a resumed session) feeds the `ui/EmployeeList.tsx` panel (rendered by `App.tsx` from `game.roster`) and the entrance board. Tests: `apps/web/test/employeeRoster.test.ts` (render counter), `apps/web/e2e/employees.spec.ts`.

Phase 3 reconnect (REQ-NET-005/006): `App.tsx` renders `ui/ConnectionBanner.tsx` (countdown, "Connection lost" + Rejoin) from `Connection` status, detaches the game on a drop and calls `Game.attachRoom` for a resumed session (prediction `resync`, `RemoteAvatars.rebind`, roster `rebind`); a fresh Rejoin builds a new `Game`. Remote nameplates show the marker via `presenceLabel` (`game/hud/activityLabel.ts`). Tests: `apps/web/test/reconnect.test.ts`, `connectionBanner.test.ts`, `remoteAvatars.test.ts`, server `apps/server/test/officeRoom.test.ts`, e2e `reconnect.spec.ts`.

Phase 2 extras: `apps/web/src/game/interaction/extras.ts` sends drink and sofa-seat intents and returns local cabinet feedback; the server runs drink/wave timers (no client timers); `App.tsx` shows timed toasts and the wave hint. Remote avatars snap to the seat socket when `seatId` is set (`remote/RemoteAvatars.ts`). Tests: `apps/web/test/extras.test.ts`, `remoteAvatars.test.ts` (REQ-INT-003/004, REQ-AVATAR-004).

Phase 2 identity: `apps/web/src/ui/JoinScreen.tsx` validates the join form, shows connecting and join-error states (Phase 3); `identityStorage.ts` safely persists drafts (tests: `apps/web/test/identityStorage.test.ts`). `App.tsx` owns join/exit lifecycle (one `Connection`; the joined room reaches `Game` as `netRoom`; door exit leaves the room); `apps/web/src/game/hud/Nameplate.ts` renders player and remote names and activity (label from `hud/activityLabel.ts`) through Game's CSS2D overlay; `avatar/AvatarView.ts` loads each avatar GLB once per `avatarId` and clones it.
